# Bale Robe Interactive Web Map

An interactive web mapping project focused on Bale Robe, Oromia, Ethiopia. The project explores how Geographic Information Systems (GIS) and web mapping can support urban growth analysis, land-use planning, accessibility assessment, and spatial decision-making.

## 🌍 Live Demo

**Explore the web map:** https://robewebmap.vercel.app/

## 📌 Project Overview

Bale Robe is an urban area experiencing changes in its built environment, road network, and land-use patterns. Understanding these changes is important for sustainable urban development and evidence-based planning.

This project presents a web-based mapping approach for exploring spatial information about Bale Robe and communicating GIS analysis through an accessible online interface.

## 🎯 Objectives

- Explore urban growth and land-use patterns in Bale Robe.
- Support spatial understanding of the built environment and road network.
- Present geographic information through an interactive web map.
- Demonstrate how GIS can contribute to land-use planning and urban decision-making.
- Develop practical skills in GIS analysis, web mapping, and geospatial communication.

## 🗺️ Key Project Areas

Depending on the layers available in the live application, the project may cover:

- **Land use and land cover:** Understanding the distribution and change of major land-cover classes.
- **Urban growth:** Exploring the spatial expansion of built-up areas.
- **Road accessibility:** Examining the road network and proximity to roads.
- **Terrain analysis:** Using elevation and slope information to understand physical land characteristics.
- **Land suitability:** Supporting preliminary identification of areas with different levels of suitability for planning.
- **Environmental screening:** Exploring terrain and drainage-related considerations relevant to urban development.

## 📊 Data and Methodology

The wider Bale Robe GIS project considers the following types of data and analysis:

1. Satellite imagery for land-use and land-cover mapping.
2. Digital Elevation Model (DEM) data for elevation and slope analysis.
3. Road network data for accessibility assessment.
4. River and drainage information for preliminary environmental screening.
5. GIS overlay and spatial analysis for land-suitability assessment.

The wider research project examines land-use and land-cover conditions for 1995, 2016, and 2024 using supervised classification methods. Include these dates and methods in the web-map documentation only where they correspond to the datasets and analyses represented in the application.

## 🌱 Potential Applications

- Urban and land-use planning

## ⚠️ Limitations

The map should be interpreted according to the accuracy, completeness, and dates of its underlying datasets. Preliminary GIS suitability or flood-sensitivity results should not be treated as final engineering assessments, official land-use decisions, or definitive flood predictions without appropriate validation.
